# 多位置 VLM 定位稳定性评估设计

## 目标

在不改变相机、图像分辨率、机械臂相对距离、模型和提示词的前提下，把当前单个红块位置的四张定位样本扩展为五个红块位置、共二十张样本，判断 VLM 红块框中心误差是稳定偏差、随机抖动还是机械臂遮挡造成的可见性失败。

本轮只做离线诊断，不接入机械臂闭环控制，也不根据四张旧样本直接添加固定坐标补偿。

## 实验变量

保持不变：

- 固定正俯视相机及相机矩阵；
- 图像分辨率 `448 x 448`；
- 末端与红块的 XY 相对距离 `0.20m`；
- `qwen3-vl-flash` 模型及 grounding 提示词；
- left、right、front、back 四种机械臂相对姿态；
- 世界坐标反投影算法和工作平面高度。

唯一主动变化：

- 使用 seeds 42–46 生成五个可复现的红块位置。

每个红块位置分别拍摄四种机械臂姿态，因此总样本数为 `5 x 4 = 20`。

## 数据与目录隔离

新实验使用独立的样本目录和运行名称，不覆盖当前 seed 42 的四张样本及其定位结果。每个样本继续拆分为：

- `samples.jsonl`：只包含可发送给 VLM 的图片路径、指令和样本元数据；
- `diagnostics.jsonl`：保存仿真红块真值和相机矩阵，仅供离线评分；
- grounding 预测文件：保存 VLM 返回的红块框；
- backprojection 结果与摘要：保存像素中心、预测世界坐标和定位误差。

`diagnostics.jsonl` 还保存红块在当前机械臂姿态下的可见像素数、移除机械臂后的参考像素数及两者比值。这些仿真分割真值只用于离线归因，不进入 VLM 输入。

四类文件通过唯一的 `sample_id` 连接，任何缺失、重复或无法配对的 ID 都应终止该阶段或记为明确的样本错误。

## 执行流程

1. 将分层均衡采样的 seed 数从 1 扩展为 5，并为新实验设置独立输出名称。
2. 使用 `vla_env` 生成 seeds 42–46 的二十张图片及对应诊断真值。
3. 使用 PyBullet segmentation mask 计算每张图的红块可见率；保留清晰、部分遮挡和严重遮挡样本，不通过缩小位置范围隐藏遮挡问题。
4. 校验图片可读、样本数为 20、四个方向各 5 张，且 samples 与 diagnostics 的 ID 完全一致。
5. 调用 Qwen grounding，对二十张图逐张保存红块框；重跑时跳过已经完成的样本，避免重复调用。
6. 将每个框中心反投影到工作平面，计算它与仿真红块真实 XY 坐标的误差。
7. 汇总整体、逐方向和逐可见率分组指标，分别判断可见目标的定位精度与遮挡鲁棒性。

## 输出指标与判断规则

必须报告：

- 总样本数、有效数和失败数；
- XY 定位误差的 mean、median 和 max；
- X/Y 两轴有符号误差的均值；
- left、right、front、back 各方向的有效数和误差；
- 每个红块位置在四种机械臂姿态下的框中心变化。
- 清晰可见、部分遮挡、严重遮挡三组的样本数、有效率和定位误差。

本轮不预设“稳定偏差”的数值阈值。先查看五个位置是否呈现一致的误差方向和相近幅度：

- 如果跨位置、跨姿态仍保持相同方向和接近幅度，再设计单独的标定补偿实验；
- 如果清晰可见样本稳定而遮挡样本失败，则不做固定补偿，下一步研究双视角、历史帧或主动避让；
- 如果清晰可见样本仍随姿态或位置明显改变，则改进 grounding 提示、定位表示或使用检测/分割消融实验。

## 验收标准

- 生成 20 张可读取图片；
- samples 与 diagnostics 均有 20 条唯一且完全匹配的记录；
- 四个方向各有 5 个样本；
- 每条 diagnostics 都包含合法的红块可见像素数、参考像素数和 `[0, 1]` 可见率；
- grounding 对每个样本都保存成功结果或明确错误，不允许静默丢失；
- backprojection 摘要可以复现整体指标和逐方向分析；
- 在读取真实结果前，不宣布固定补偿可行，也不进入在线控制。

## 测试与风险控制

配置契约测试应固定 seed 数、独立输出目录和正数采样参数。采样测试应验证五个 seed 与四个方向组成二十个唯一 ID。评估测试应验证逐方向分组统计不会忽略失败样本。

主要风险是 Qwen 调用中断、产生无效框或红块被机械臂遮挡。预测仍按样本即时保存，并通过既有断点续跑机制避免重复付费；无效框保留为可诊断错误，不把它解释为 `stop` 或零误差。遮挡样本保留并单独统计，不与清晰可见样本混成一个无法解释的平均值。
